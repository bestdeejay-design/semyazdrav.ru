# Семяздрав — сайт продукта

Статический сайт на русском языке для жидкого органического концентрата «Семяздрав» (250 мл): продающий лендинг, база знаний из 25 статей и SEO-разметка. Чистый HTML, CSS и JavaScript без сборщика и внешних зависимостей.

**Домен:** [semyazdrav.ru](https://semyazdrav.ru) · **Публикация:** GitHub Pages из ветки `main`.

## Быстрый старт

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Сайт статический: сборка для просмотра не нужна.

## Структура

| Путь | Назначение |
|---|---|
| `index.html` | Продающий лендинг: герой, состав, применение, калькулятор дозировки, FAQ |
| `styles.css` | Визуальная система лендинга, адаптив |
| `script.js` | Мобильная навигация и калькулятор дозировки |
| `articles/content.json` | Исходные тексты 25 статей |
| `articles/tips.json` | Практические советы для статей |
| `articles/<slug>/index.html` | Сгенерированные страницы статей |
| `articles/index.html` | Фильтруемая библиотека статей |
| `scripts/build_articles.py` | Генератор статей, библиотеки, `sitemap.xml`, `robots.txt`, `SEO_PLAN.md` |
| `public/images/botanical-hero.jpg` | Иллюстрация для первого экрана — **не фото упаковки** |
| `public/images/og-cover.jpg` | Open Graph-обложка 1200 × 630 |
| `CNAME` | Домен GitHub Pages — не удалять |
| `.nojekyll` | Отключает обработку Jekyll, файлы отдаются как есть |

## Сборка контента

После правок в `articles/content.json` или `articles/tips.json`:

```bash
python3 scripts/build_articles.py
```

Генератор проверяет, что статей ровно 25, слаги уникальны и совпадают с `tips.json`, затем перезаписывает страницы статей, библиотеку, `sitemap.xml`, `robots.txt` и `SEO_PLAN.md`.

- Канонический адрес по умолчанию — `https://semyazdrav.ru`.
- Для локального или тестового стенда можно переопределить базу: `SITE_BASE_URL=http://localhost:4173 python3 scripts/build_articles.py`.
- Дата контента по умолчанию — `2026-09-30`; переопределяется через `CONTENT_DATE=YYYY-MM-DD`.

## Публикация

GitHub Pages настроен на ветку `main`, корень репозитория, тип сборки `legacy`. Каждый пуш в `main` запускает сборку и деплой.

```bash
gh run list --repo bestdeejay-design/semyazdrav.ru --limit 3
gh run watch <run-id> --repo bestdeejay-design/semyazdrav.ru --exit-status
```

Проверка настроек:

```bash
gh api repos/bestdeejay-design/semyazdrav.ru/pages
```

`CNAME` содержит `semyazdrav.ru`. Домен и HTTPS настраиваются в GitHub Settings → Pages; файл `CNAME` и `.nojekyll` не удалять.

### Домен и DNS

Домен `semyazdrav.ru` зарегистрирован на reg.ru. Сейчас его DNS делегирован на Tilda, поэтому GitHub Pages не получает трафик, а домен отдаёт заглушку Tilda. Для запуска нужны записи:

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `bestdeejay-design.github.io.` |

После переключения DNS GitHub выпускает сертификат; затем в Settings → Pages включается **Enforce HTTPS**.

## Контент и продукт

- В каталоге один товар — универсальный концентрат 250 мл. Разделы про орхидеи, фиалки, пальмы и рассаду — сценарии применения, а не отдельные SKU.
- Характеристики продукта: NPK 1,1 / 3,3 / 7,1; гуминовые и фульвовые кислоты 36,8 г/л; янтарная кислота 1 г/л; аминокислоты и витамины A, E, PP, B₁, B₂; 250 мл на до 250 л рабочего раствора; срок годности 48 месяцев.
- Не добавлять цены, отзывы, контактные данные и обещания гарантированного роста или цветения. Актуальные цена, наличие и продавец — на Wildberries.
- Все статьи носят справочный характер и не заменяют инструкцию на упаковке.

## Ассеты

`public/images/botanical-hero.jpg` и `public/images/og-cover.jpg` — иллюстрации, а не фотографии реального флакона. Перед рекламным трафиком их нужно заменить реальными фото продукта. OG-обложка должна оставаться 1200 × 630; после замены пересобрать статьи, чтобы обновились ссылки на изображение.
