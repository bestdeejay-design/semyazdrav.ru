# Семяздрав — лендинг продукта

Адаптивный одностраничный сайт на русском языке для жидкого органического концентрата «Семяздрав» (250 мл). Сайт сделан на чистом HTML, CSS и JavaScript, без сборщика и внешних зависимостей.

## Локальный просмотр

```bash
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Публикация

Статические файлы размещаются из корня ветки `arena/01a0efc7-semyazdrav-ru` через GitHub Pages. После включения Pages адрес проекта: `https://bestdeejay-design.github.io/semyazdrav.ru/`.

## Материалы и содержание

- `index.html` — продающая главная страница с характеристиками и ссылкой на карточку товара.
- `styles.css` — адаптивная визуальная система главной страницы.
- `script.js` — мобильная навигация и калькулятор дозировки.
- `articles/content.json` и `articles/tips.json` — исходные тексты 25 статей.
- `scripts/build_articles.py` — генератор статических страниц, базы знаний, `sitemap.xml`, `robots.txt` и `SEO_PLAN.md`.
- `articles/` — 25 отдельных индексируемых страниц и фильтруемая библиотека.
- `public/images/botanical-hero.jpg` — иллюстративное фото для лендинга, его стоит заменить реальным фото флакона.
- `public/images/og-cover.jpg` — отдельная Open Graph-картинка 1200 × 630 для предпросмотра страниц в соцсетях.

На главной, в библиотеке и на каждой статье заполнены Open Graph/Twitter Card: заголовки и описания, а также ссылка на обложку. У статей — индивидуальные заголовки и описания; изображение пока одно общее для бренда.

Пересобрать статьи после правок:

```bash
python3 scripts/build_articles.py
```

Основные SEO-метаданные настраиваются в `scripts/build_articles.py`. Адрес по умолчанию — GitHub Pages проекта; для нового канонического адреса задайте `SITE_BASE_URL` при генерации. В каталоге включён только товар, для которого предоставлены характеристики. Разделы для разных культур — сценарии применения того же универсального концентрата, не отдельные SKU.

После включения GitHub Pages подтвердите сайт в Google Search Console и Яндекс Вебмастере, отправьте `sitemap.xml`, проверьте индексацию и отслеживайте поисковые запросы. Частотность и конкуренция ключевых фраз требуют проверки через Wordstat и Search Console — они не угадываются по одним заголовкам.
