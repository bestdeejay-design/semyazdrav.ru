# Семяздрав — лендинг продукта

Адаптивный одностраничный сайт на русском языке для жидкого органического концентрата «Семяздрав» (250 мл). Сайт сделан на чистом HTML, CSS и JavaScript, без сборщика и внешних зависимостей.

## Локальный просмотр

```bash
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Публикация

Статические файлы размещаются из корня ветки `arena/01a0efc7-semyazdrav-ru` через GitHub Pages. После включения Pages адрес проекта: `https://bestdeejay-design.github.io/semyazdrav.ru/`.

## Материалы и содержание

- `index.html` — секции, тексты, характеристики и поисковая ссылка на Wildberries.
- `styles.css` — адаптивная визуальная система.
- `script.js` — мобильная навигация и калькулятор дозировки.
- `public/images/botanical-hero.jpg` — иллюстративная AI-сгенерированная фотография; её можно заменить реальным фото товара.

В каталог включён только товар, для которого предоставлены характеристики. Разделы для орхидей, зелёных растений и рассады — сценарии применения того же универсального концентрата, не отдельные SKU. В тексте не указываются неподтверждённые цены, отзывы и характеристики.
