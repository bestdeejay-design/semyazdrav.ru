# AGENTS.md — правила проекта semyazdrav.ru

## Что это

Статический сайт продукта «Семяздрав»: лендинг, 25 SEO-статей, генератор на Python. Публикуется через GitHub Pages из ветки `main`, домен `https://semyazdrav.ru`.

## Жёсткие инварианты

- **Публикация:** GitHub Pages, ветка `main`, корень репозитория, тип `legacy`. Не менять источник Pages и не удалять `CNAME` / `.nojekyll`.
- **Канонический домен:** только `https://semyazdrav.ru`. Все `canonical`, OG/Twitter, JSON-LD, `sitemap.xml` и `robots.txt` должны указывать на него. Адреса `bestdeejay-design.github.io` в контенте запрещены.
- **Стек:** чистый HTML + CSS + JS, без сборщика, фреймворков и внешних зависимостей. Новые библиотеки — только по решению владельца.
- **Продуктовые факты:** NPK, объём, дозировка, срок годности, состав — только по этикетке и подтверждённым данным. Не додумывать.
- **Запрещено добавлять:** цены, отзывы, контактные данные, гарантии роста/цветения, медицинские обещания, внешнюю аналитику и трекеры без решения владельца.
- **JavaScript — прогрессивное улучшение:** контент и навигация должны работать без JS. Калькулятор и фильтры могут зависеть от JS.
- **Изображения:** не выдавать иллюстрации за фото упаковки. Реальные фото продукта — приоритет. OG-обложка — 1200 × 630.

## Команды

```bash
# локальный просмотр
python3 -m http.server 4173

# пересборка статей и SEO-файлов
python3 scripts/build_articles.py

# проверка, что старый домен не остался в публикуемых файлах
grep -rn "bestdeejay-design.github.io" --include='*.html' --include='*.xml' --include='*.txt' --include='*.js' --include='*.css' .

# проверка JSON
python3 -m json.tool articles/content.json >/dev/null
python3 -m json.tool articles/tips.json >/dev/null
```

## Definition of done

1. `python3 scripts/build_articles.py` отрабатывает без ошибок.
2. `grep` по `bestdeejay-design.github.io` в HTML/XML/TXT/JS/CSS не находит совпадений.
3. Локально отдают 200: `/`, `/articles/`, три случайные статьи, `/sitemap.xml`, `/robots.txt`, `/public/images/og-cover.jpg`.
4. Нет битых внутренних ссылок и отсутствующих файлов.
5. Проверены mobile 390 px и desktop 1440 px; нет горизонтального скролла и обрезанного текста.
6. `CNAME` содержит `semyazdrav.ru`, `.nojekyll` на месте.
7. После пуша в `main` сборка GitHub Pages завершилась успешно.

## Ветки и PR

- Рабочая ветка — от свежего `main`, имя по задаче.
- В `main` не пушить напрямую: изменения идут через PR.
- В описании PR — что изменено, как проверено, какие скриншоты приложены.
- Не менять настройки репозитория и Pages без решения владельца.

## Файлы, требующие осторожности

| Файл | Правило |
|---|---|
| `CNAME` | Не удалять и не менять без решения владельца |
| `.nojekyll` | Не удалять |
| `scripts/build_articles.py` | Менять только осознанно; генератор перезаписывает 26 HTML-файлов |
| `articles/content.json` | Источник истины для текстов статей |
| `index.html` | Лендинг; canonical и OG-URL держать на `https://semyazdrav.ru` |

## Текущее состояние и следующая задача

- Код и SEO-база готовы, Pages собирается из `main`.
- Домен пока смотрит на Tilda — до смены DNS публичный сайт не открывается.
- Следующая задача — корректные визуалы: реальные фото флакона вместо иллюстраций, обновлённая OG-обложка, проверка первого экрана на mobile и desktop. Тексты и продуктовые факты при этом не переписывать без отдельного решения.
