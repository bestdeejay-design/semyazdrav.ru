# Кросс-промо «Семяздрав» × «Ферма Рунская»

Пакет взаимного кросс-промо двух дружественных проектов: [semyazdrav.ru](https://semyazdrav.ru) и [fermaruna.ru](https://fermaruna.ru). Статус прав и подтверждений — в [`PERMISSIONS.md`](PERMISSIONS.md).

## Состав

| Путь | Что внутри |
|---|---|
| `logos/semyazdrav-logo.svg/.png/@2x.png` | Локап «Семяздрав»: знак-лист (`favicon.svg` сайта) + слово, для светлых фонов |
| `logos/fermaruna-logo.svg/.png/@2x.png` | Локап «Ферма Рунская»: официальный знак-росток из репозитория fermaruna + типографика «ферма / Рунская» |
| `logos/fermaruna-mark.svg`, `fermaruna-mark-512.png` | Знак-росток «Рунской» отдельно (оригинал `favicon.svg` из репозитория партнёра и его растеризация) |
| `logos/fermaruna-icon-bee-512.png` | Официальная иконка фермы с пчелой (`assets/img/icon-512.png` из репозитория партнёра); использована в баннерах |
| `banners/semyazdrav-to-fermaruna-*.png` | Баннеры про «Рунскую» для размещения на semyazdrav (1200×300, 600×300, 300×250): официальное фото фермы + иконка-пчела |
| `banners/fermaruna-to-semyazdrav-*.png` | Баннеры про «Семяздрав» для размещения на fermaruna (те же размеры): настоящее фото флакона |
| `copy.md` | Три варианта текстов блока: нейтральный, редакционный, продуктовый |
| `utm.md` | Ссылки и правила UTM |
| `handoff-fermaruna.md` | Готовая инструкция + HTML/CSS для агента, размещающего блок на fermaruna.ru |
| `PERMISSIONS.md` | Что подтверждено, что можно и чего нельзя утверждать |

## Как это выглядит на semyazdrav.ru

Блок «Наш партнёр — ферма „Рунская“» стоит на главной перед футером: фото, локап, одна фраза, ссылка с UTM. Блок не конкурирует с CTA «Купить на Wildberries» и не утверждает, что ферма использует или рекомендует продукт.

## Цвета для ручной вёрстки

- «Семяздрав»: forest `#163c2b`, cream `#f7f6ef`, leaf `#688c5b`.
- «Ферма Рунская»: forest-900 `#13291c`, cream `#f6f1e3`, honey `#e8b75a`, шрифты Alegreya + Manrope.
